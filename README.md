# Лабораторная работа № 2. Вариант 4

Тема: «Обучение без учителя. Понижение размерности. Обнаружение аномалий.
Кластеризация.»

Проект на Python для Visual Studio Code. Включает полный цикл анализа:
загрузку данных варианта 4, корреляционный анализ, PCA, SVD, ICA,
кластеризацию 12 алгоритмами, оценку качества и автоматическую сборку
отчёта в формате DOCX.

## Быстрый запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python scripts/run_all.py
```

После выполнения:

- рисунки — в каталоге `figures/`;
- метрики — в `results/part1_results.json`, `results/part2_results.json`,
  `results/clustering_metrics.csv`;
- отчёт — `report/Лабораторная_работа_2_Вариант_4.docx`.

Отдельные этапы:

```powershell
python scripts/run_part1.py    # PCA, SVD, ICA
python scripts/run_part2.py    # кластеризация
python scripts/build_report.py # только сборка DOCX
```

## Данные варианта 4

- `Lab2_Dataset_PCA.xlsx`: 194 наблюдения, признаки `a, b, c, d, e`,
  целевая метка `y` (2 класса по 97 наблюдений).
- `Lab2_Dataset_Clustering.xlsx`: 144 наблюдения, признаки `a, b`,
  целевая метка `y` (4 класса: 36, 37, 36 и 35 наблюдений).

Метки `y` не используются при обучении моделей — только для визуализации
и расчёта внешних метрик ARI и NMI.

## Основные результаты

- PCA и SVD: первые две компоненты объясняют 53,92 % дисперсии,
  четыре — 91,51 %; для порога 80 % нужно четыре компоненты.
- ICA: MSE восстановления уменьшается с 0,6903 (1 компонента) до 0,0849
  (4 компоненты) и практически до нуля при 5 компонентах.
- Кластеризация: лучшее согласие с эталоном у Gaussian Mixture
  (ARI = 0,541; NMI = 0,546; 4 кластера); второе место — Spectral
  Clustering (ARI = 0,272). Плотностные методы дают много шумовых точек
  и слабое согласие с эталонной разметкой.

Все стохастические алгоритмы используют `random_state = 42`, поэтому
результаты воспроизводимы.
